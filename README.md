# Patient_Record_Analysis
# 🏥 Patient Records SQL Analysis

## 📌 About the Project

This project is a **SQL practice and data analysis project** based on a Patient Records dataset. It focuses on using **MySQL queries** to retrieve, filter, analyze, and extract meaningful information from patient data.

## 🛠️ Skills & Concepts Practiced

* MySQL
* SELECT, WHERE, ORDER BY
* Aggregate Functions
* GROUP BY & HAVING
* JOINs
* Date & Time Functions
* Subqueries
* Filtering and Sorting
* Data Analysis using SQL

## 📊 Dataset

The dataset contains patient-related information such as:

* Patient details
* Age and Gender
* City
* Disease
* Blood Pressure
* Cholesterol
* BMI
* Smoking Status
* Treatment Cost
* Admission and Discharge Dates

## 🎯 Objective

The main objective of this project is to strengthen my **SQL query-writing and analytical thinking skills** by solving different data-related questions using a real-world-style healthcare dataset.

## 🚀 Learning Outcome

Through this project, I improved my understanding of SQL and gained more confidence in using queries to analyze structured data and extract useful insights.
